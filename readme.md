 Análise Exploratória de Dados: Emendas Parlamentares e Transparência
 Visão Geral:
Este projeto une os fundamentos da Ciência de Dados ao compromisso com a transparência pública. Através de uma análise exploratória (EDA) em um dataset de emendas parlamentares brasileiras (2014-2023), o objetivo foi transformar registros brutos em informações estruturadas, auditáveis e estratégicas.

A proposta vai além do código: trata-se de utilizar o raciocínio analítico para entender como os recursos públicos são alocados e distribuídos.

 Desenvolvimento Técnico e Metodologia:
O projeto foi estruturado em um pipeline focado na integridade e qualidade dos dados, utilizando a biblioteca Pandas:

Diagnóstico e Tipagem: Identificação de inconsistências críticas, como valores financeiros lidos como texto (object), preparando o terreno para o tratamento de dados monetários.

Dicionário de Variáveis: Mapeamento semântico de identificadores, localizações geográficas e campos financeiros para garantir uma análise contextualizada.

Auditoria de Integridade: Verificação de duplicatas e limpeza da base, assegurando que a análise reflita transações únicas e confiáveis.

Estatística Descritiva: Uso de métodos como .describe() para extrair a distribuição temporal e regional do orçamento, identificando padrões de gasto ao longo da última década.

 Competências Aplicadas:
Manipulação de Dados: Experiência prática em Python e Pandas para saneamento de grandes volumes de dados.

Pensamento Crítico: Estruturação lógica do problema antes da implementação técnica.

Storytelling de Dados: Capacidade de traduzir diagnósticos técnicos em conclusões claras sobre a realidade do orçamento público.

 Python 3.x, Pandas, Google Colab e VS Code.
